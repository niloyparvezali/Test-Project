# TurfClub — Mobile-First Main Project

This version is the Firebase production project with the responsive system prioritized for mobile first, then enhanced for tablet and desktop.

## Responsive priorities
- Base CSS targets phone widths first (320px+).
- Tablet enhancements begin at 600px.
- Desktop navigation/sidebar enhancements begin at 900px.
- Wide desktop enhancements begin at 1100px.
- No page-level horizontal overflow.
- Search/filter controls stack and expand cleanly on narrow screens.
- Public navigation uses a mobile menu below desktop breakpoint.
- Admin sidebar becomes a mobile drawer.

Core Firebase, booking, financial, authentication, and existing business logic are preserved.
